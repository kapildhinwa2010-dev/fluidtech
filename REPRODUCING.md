Reproducing every number
Everything in this repository is regenerated by the commands below.  They
all run on CPU, in pure NumPy, with no downloads.
The checks
python selftest.py                 # 38 checks, ~4 s
python superfluid_single.py --selftest   # the same, from the single file
python tests/run_without_pytest.py  # the unit tests, without pytest
python -m pytest -q tests           # ... with pytest, if you have it
The experiments
python experiments/run_all.py            # a fast smoke run of everything
python experiments/run_all.py --full     # everything, at full size (~40 min)
| experiment|what it measures|output|
| ---|---|---|
| e1_prior_perplexity.py|does a training-free domain prior help a  frozen  LM?|results/e1_prior.json|
| e1 --sweep|how does that benefit depend on the base model's quality?|results/e1_sweep.json|
| e2_scaling.py|the two-axis scaling law (anchors vs. exact budget)|results/e2_scaling.json|
| e4_gbalance.py|the frustration index, and whether λ₂ predicts quality|results/e4_gbalance.json|
| e5_graft.py|the money experiment: 11 selection policies over 1M tokens|results/e5_graft.json|
| e6_graft.py|the graft : attach safety, perplexity, capability|results/e6_graft.json|
| e6_real_corpus.py|the same on real English, per tier|results/e6_real.json|
| e6_real_corpus.py --tokenizer bpe|... at a  subword  granularity|results/e6_real_bpe.json|
| e7_lossy_fix.py|the fix for the diffusion tier's training signal|results/e7_lossy_fix.json|
The theory report is regenerated by `python build_report.py` →
`docs/index.html`.
The optional GPU run
`experiments/gpu_graft.py` repeats the three graft measurements on a real
pretrained LLM with a real tokenizer.
It has not been executed in the development sandbox (no GPU, no torch,
3 GB of RAM).  It is written to be reviewed and run on a GPU box:
pip install torch transformers accelerate
python experiments/gpu_graft.py --model Qwen/Qwen2.5-0.5B-Instruct
Budget: a few minutes on one H100 PCIe (~$0.67/hr spot) ⇒ under $3 for
the whole run, model download included.
Determinism
Every experiment takes a `--seed` and fixes its own RNG.  The selftest is
deterministic.  Small run-to-run differences are possible in the training
loops because the CPU BLAS is not bit-deterministic across machines; the
reported numbers were produced on one machine and are reproduced to within
±0.01 nats.
