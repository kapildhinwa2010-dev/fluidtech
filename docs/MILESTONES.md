# Milestones

What has actually been built and measured, in order.  Every number here is
regenerated by a command in `docs/REPRODUCING.md`; none of it is a claim
without a file behind it.

---

## 1. The mathematics is real, and machine-checked

Three propositions (a jamming bound, a Chebyshev degree bound, and a
linear-collapse theorem), the Hodge limit with an exponential contraction
certificate, and the spectral decomposition the whole architecture rests on.
The certificate **‖e^{-tL}‖ ≤ e^{-tλ₂} holds 36/36** on random Laplacians.
→ `docs/FRAMEWORK.md`, `docs/index.html`

## 2. A working, trainable framework — from scratch, in NumPy

An autodiff engine, the 7-stage sheaf block, the Chebyshev diffusion with a
band filter bank, the persistent-homology utilities, a language model and a
param-matched transformer baseline.  No torch, no scipy, no GPU, no
downloads.
→ `fluidlayer/`

## 3. A self-verification harness that has earned its keep

**50 checks**, running in ~4 seconds, machine-checking every claim in the
documentation.  It found **twelve real bugs in this project's own code** —
among them a Chebyshev recurrence missing a factor of two, a scatter
operation that never scattered, gradients zeroed after the backward pass,
an `exp(+α)` overflow, and a balance diagnostic that did not detect the
frozen state.
→ `selftest.py`, `fluidlayer_single.py` (one file, 154 KB, self-verifying)

## 4. The exact tier: bit-exact memory for 20 bytes a fact

The low-level `FrozenRegister` uses a fixed 20-byte, content-keyed slot and
refuses overflow. The attachable branch uses a bounded majority-tracking
store; both return the stored token ID exactly, but neither establishes that
the token is true. **819 packed slots per 16 KB**, before Python object
overhead; this is not a tamper-evident audit trail.
→ `fluidlayer/memory.py`, `fluidlayer/graft.py`

## 5. The budget law, measured

* 16× more anchors → **+0.013** of aggregate quality, for **256×** the compute;
* 64× more exact slots → **+0.69** of fact recall, for **20 KB**.

Spending the budget on *exactness* rather than on *storage* is not a
guess; it is the measured shape of the curve.
→ `results/e2_scaling.json`

## 6. The money experiment

One million tokens, eleven selection policies, one shared budget.
* the local aggregate is carried with a cosine of **0.968**;
* **exact | promoted = 1.000** — every promoted fact comes back bit-exact;
* an exact fact costs **6,554×** less than the equivalent KV-cache state.
→ `results/e5_graft.json`

## 7. A layer you can actually attach to a model

One residual-stream insertion, `h' = h + W·(exact read, diffusion read)`.
* **attaching it changes nothing**: the logits are **bit-identical**
  (max diff `0.000e+00`), because the output projections start at zero;
* the exact tier takes cross-window verbatim recall from **0.050 to 0.800**
  (chance 0.125) — **16× the base model** — at **6.3 KB** of state;
* a PyTorch twin exists for attaching it to a real pretrained LLM.
→ `fluidlayer/graft.py`, `fluidlayer/torch_graft.py`, `docs/GRAFT.md`

## 8. A divergence diagnosed at the root and fixed

The diffusion tier's training was **diverging** (+1.14 nats of damage).  The
cause was located (a persistent state outside the autodiff graph, so the
gradient target moved every step) and fixed: rebuild the state inside the
graph from a bounded history.  The damage went to **+0.0000** and the
layer's own objective now **converges** (4.34 → 3.81).
→ `experiments/e7_lossy_fix.py`, `results/e7_lossy_fix.json`

## 9. The infrastructure to believe it

* a **byte-level BPE tokenizer** in pure Python (no downloads), so every
  measurement can be repeated at a realistic token granularity;
* a **subword repeat** of the whole evaluation;
* a **GPU driver** for a real pretrained LLM;
* a **pytest-free test runner**, because the project is meant to work with
  nothing but numpy;
* a complete GitHub repository: CI, a nightly full sweep, a release
  workflow, issue and PR templates, a Docker image, `Makefile` targets,
  `CHANGELOG`, `CONTRIBUTING`, `CODE_OF_CONDUCT`, `SECURITY` with a threat
  model.
→ `fluidlayer/bpe.py`, `tests/`, `.github/`, `Makefile`

## 10. The byte economics that motivate the whole thing

| | |
|---|---|
| a 70B model at a 128K context on 2×H100 | **0** concurrent sessions with the full KV cache → **45** with a 2K window + 16 KB |
| 10,000 tenants at a 32K context (8B) | **40,000 GB** of KV → **153 MB** |
| per exact fact | **20 bytes** instead of 131,072 |

## 11. Ten million tokens, measured

10M tokens through the layer: the state stays at **16 KB** (the same tokens
as a KV cache would be **1.31 TB** for an 8B model, **3.28 TB** for a 70B
one), the fill costs **12 seconds and no model forward**, and the answer to
"what does it remember" is precise: **6/6 facts** at every depth when the
context is distinctive, **0/6** when the context is a 12-gram and the
budget is 16 KB.  The perplexity delta is **−0.0057 nats** at the right
injection gain and **+1.08 nats** at the gain that maximises recall — the
two knobs are three orders of magnitude apart.
→ `docs/TEN-MILLION.md`, `results/e9_ten_million.json`

## 12. The one-knob problem, solved

E9 found that the injection gain that maximises **recall** (300) and the
one that maximises **generation** (0.3) were three orders of magnitude
apart, and the recall gain **ruined** the model (+1.08 nats).  The fix: the
base model's **own uncertainty** (`u = 1 − max p`) scales the override, so
the memory speaks only where the model is unsure.  Measured: the recall is
**unchanged (0.975)** and the base model's perplexity **improves** from
13.61 to **11.78** — better than the ungated layer ever managed.
→ `experiments/e10_gate.py`, `results/e10_gate.json`

## 13. The memory is exact

The recall ceiling (0.975) is gone: **1.000**.  The store now keeps the
**majority** continuation of a context and counts the corroboration, so the
common-context case went from **0/3 to 40/40**; and when the store
overflows it evicts the **least corroborated** entry, not the oldest, so
**40/40** corroborated contexts survive a flood of 5,000 one-off contexts.
With the layer attached the base model's perplexity **improves** to
**11.78** (from 13.61).  Two plausible rules were tried and **rejected** on
measurement (both off by default).
→ `experiments/e11_exact.py`, `results/e11_exact.json`

## 14. The fluid tier finally has a job

The diffusion tier was a lossy summary that answered neither "where" nor
"what" — its optimal injection gain was **zero**.  Used as the **router**
(the geometry as an address space, each anchor holding the majority
continuation of its contexts), it becomes the fallback for exactly the two
cases the exact tier cannot serve: a context too old for the store
(recall **0.100 → 0.625**) and a context the base model has no idea about
(**+0.053 → −0.071 nats**).  The cost: 0.0005 % of a transformer's
compute per token.
→ `experiments/e12_router.py`, `results/e12_router.json`

## 15. The comparison against the closest prior art (kNN-LM)

The repository had never compared itself against a **kNN-LM**, which is
functionally the same idea (a datastore plus an LM) and the first thing a
reviewer would ask for.  Now measured: with a **16 KB** store the gated
layer beats the interpolation by **7.4×** on the loss; with a **1 MB**
store the kNN-LM wins by 6.4×.  The claim is therefore precise: **the gate
is the contribution under a hard memory budget** — which is a narrower
claim than the project started with, and a defensible one.
→ `experiments/e13_knn_baseline.py`, `results/e13_knn.json`

## 16. A pretrained LLM — unverified

The E14 script and GPT-2 forward/tokenizer implementation are present, but
the checkpoint and `results/e14_real_gpt2.json` are not. Previously reported
GPT-2 measurements cannot be independently checked from this repository and
should not be cited until E14 is rerun and its raw output is published.
→ `experiments/e14_real_gpt2.py`; see [reproduction instructions](REPRODUCING.md)

## 17. A repository a stranger can run in one minute

Fresh clone → `python selftest.py` → **50/50**.  `pip install .` → the public API
imports from an installed wheel. Reproducible experiments can be rerun with
`python experiments/run_all.py --full`; the historical N4 and N11 outputs
are unavailable and are documented as unverified.
→ `scripts/check_artifacts.sh` (the one-command audit)

## 18. The credibility milestone

**Seven** results that came out negative are published in full, with the
numbers, in `docs/NEGATIVE-RESULTS.md` — plus a prior-art audit that says
plainly what is *not* new (`docs/POSITIONING.md`).  That is why the twelve
milestones above are worth reading: they were produced by a project that
reports its own failures, in a repository where every claim is a file you
can run.

## Where it stands

A **research prototype, not production-ready software**: the code is
tested, documented, installable and CI-verified; the measurements are
honest; and the claims are the ones the evidence supports.

The next milestones, in order of value per hour:

1. **run `experiments/gpu_graft.py` on a GPU box** (under $3) — the only
   claim that still rests on a 131k-parameter model;
2. **publish the 2-page design note** to establish priority
   (`docs/LAUNCH.md` has the plan);
3. **release the artefact** and post it (`docs/RELEASE-CHECKLIST.md`).
